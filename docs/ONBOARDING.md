# 首次使用与偏好设置

首次打开一个没有个人记录的新 v4 数据目录时，软件显示欢迎页：左侧介绍课表、任务专注与回看，右侧设置称呼和偏好。这是本机个性化设置，不需要注册账号或密码。

已有课表、任务、聊天、计时等记录的用户升级后直接进入工作台。点击工作台的「设置使用偏好」，或「设置 → 我的节奏 → 称呼与偏好设置」，可以打开同一页。窗口较小时内容可滚动，保存和取消/跳过按钮固定在底部。

## 哪些选择会生效

| 项目 | 实际行为 |
| --- | --- |
| 昵称 | 用于工作台与助手问候，也随规划上下文提供给用户配置的模型。可留空，不要求真实姓名。 |
| 使用用途 | 学习备考、项目推进、习惯养成、生活安排可多选。改变工作台和总对话的推荐话题，并进入模型规划上下文；不会自动创建任务或课程。 |
| 一次专注时长 | 15、25、45 分钟或自定义 5–90 的整数分钟。未写明时长的新任务默认用此值；本地长任务和首次开始的未分段任务按此基准拆分，分段总和保持原总时长。明确写出的任务时长及已有分段不被覆盖。最多 12 段，特别长的任务每段可能超过偏好时长，建议分到多天。 |
| 安排节奏 | 紧凑高效、均衡安排、多留空白分别建议段间休息 3、5、10 分钟，并预留每日可安排时间的 10%、20%、35%。填写可选的每日时间后，工作台与按日推算的周容量、模型上下文使用扣除留白后的建议专注上限。明确填写的周容量不重新折算。 |
| 提醒方式 | 保持安静：关闭专注、课前及任务开始前的自动声音与通知；仅结束提醒：只在专注段到时提醒；开始与结束：另含开始专注及课前/任务开始前提醒。课前提前量在「我的节奏」内设置，0 表示关闭。 |

例如每天可安排 120 分钟、选择「多留空白」，建议专注上限是 78 分钟，其他时间留给休息和临时事项。休息是建议，不会自动启动休息倒计时或替用户暂停已有计时；到时提示会说明建议休息多久。

本地规则按所选时长拆分和计算容量；连接模型后，模型还会收到用途、称呼、专注时长、休息间隔与每日专注上限。模型是否提出合适的具体内容仍取决于所选服务，提议需要用户确认后才会写入。偏好不会自动重新安排已有课程或任务。

## 保存、跳过和升级

- 点选只修改草稿；点击保存并写入成功后才生效。取消、关闭或 Esc 不保存草稿。
- 「暂时跳过」忽略所有未确认选择，保留原偏好，标记欢迎流程已处理；以后可从设置再次打开。跳过不会为旧数据启用新的留白比例。
- 欢迎页在没有旧记录的新数据目录首次显示。已有用户只看到工作台入口，不会被弹窗强制打断。升级仅为缺失字段提供兼容默认值；课表、任务、计时、模型配置和密钥保留。
- 正在计时时修改偏好，会合并到最新状态，不覆盖已走过的步骤、暂停累计时间或计时起点；已有任务不会被重新拆分。
- 数据继续保存于 `%LOCALAPPDATA%\TPlanV4\tplan.sqlite3`。Windows 通知依赖程序保持打开；系统免打扰可能隐藏横幅。安静模式仍保留计时数字、超时颜色和用户操作后的保存反馈。

## 开发与验收

- `v4/js/onboarding.js`：首次使用与设置共用的草稿表单。
- `v4/js/core.js`：偏好校验、兼容字段、容量与分段规则。
- `v4/js/app.js`、`agent.js`、`platform.js`：推荐入口、默认值、模型上下文、提醒分发。
- `v4-desktop/MainWindow.cs`：Windows 提示音及通知桥接。悬浮窗的 `TimerWindow.cs` 不需要改动。
- `npm test`：含偏好、数据保留、任务分段、容量和模型请求契约测试。
- `T计划 v4.exe --self-test 尚不存在的目录`：创建隔离的数据库，验证首次使用、跳过、重启、取消、失败保存、自定义时长、提醒分发和已有桌面回归。通知自检计数不播放声音；真实系统横幅是否显示仍受 Windows 设置影响。模型测试使用模拟响应，不调用用户付费服务。
