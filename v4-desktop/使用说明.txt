T计划 v4.1.0 · Windows x64 免安装版（课表导入）

开始使用
1. 把 ZIP 完整解压到电脑上的文件夹，例如 D:\Apps\TPlanV4。
2. 打开 package-4.1 文件夹，双击「T计划 v4.exe」。
3. 请保留同目录的 app、runtime、DLL 和许可证文件，不要单独移动 EXE。
4. 不用安装 Node.js、Python，也不用启动网页服务器。

官方下载与更新：https://github.com/fanzite629/T-plan-4/releases
下载 ZIP 后可用同一发布页中的 .zip.sha256 核对压缩包，解压后可用 SHA256SUMS.txt 核对包内文件。

数据保存在 %LOCALAPPDATA%\TPlanV4\tplan.sqlite3，独立于 v3 和浏览器原型。
软件文件夹是免安装的，个人数据保存在当前 Windows 用户目录；不是随 U 盘自动迁移数据的模式。
设置 → 数据：可导出 JSON 备份，再在另一台电脑导入。
如果曾在浏览器中使用 v4，请先从浏览器版导出数据，再在桌面版导入。
API 密钥单独加密保存在本机，只能由当前 Windows 用户解密，不包含在 JSON 备份里。
更换电脑后需要重新填写密钥。压缩包不包含开发者的任务、聊天、API 密钥或个人数据库。

功能
首次使用：填写昵称，选择用途、专注时长、安排节奏与提醒方式，也可以跳过。
已有用户可点工作台「设置使用偏好」，或「设置 → 我的节奏 → 称呼与偏好设置」。
自定义专注为 5–90 分钟；新任务默认采用它，明确的时长和已有分段不被覆盖。
安排节奏分别建议段间休息 3/5/10 分钟、预留每日可安排时间的 10%/20%/35%。
填写每日时间后，工作台与按日推算的周容量显示扣除留白后的建议专注上限。
休息是建议，不自动开始休息倒计时。设置偏好不修改已有课程、任务或当前计时。
安静模式关闭自动提醒；仅结束提醒只在专注到时提醒；开始与结束还含课前提醒。
课前提前量仍可在「我的节奏」调整；Windows 免打扰可能隐藏通知，需要软件保持打开。

左侧「课表」：先在「学期与节次」填写第 1 教学周的周一、总周数，以及学校每节课的钟点。
这些信息保存一次，后续按节次的课程自动套用；软件不会猜你的学校作息。
进入课表后可拖入 PDF、截图、Word（.docx）、Excel（.xlsx）、CSV；也可粘贴截图到导入窗口。
选择规则优先、仅规则或已配置模型，点击开始识别。预览中可以修改课程、星期、周次、节次、教室和教师。
检查后点击「确认导入」，课程才会展开为每天的上课时段。重复项跳过，冲突和缺失信息会提示。
支持单双周（如 1-16单）、分段周次（如 1-8,10-16）、具体日期和具体开始/结束时间。
今天的课程同时显示在「全部」的今天安排中；规划助手会把未来两周课程作为已占用时间参考。
点击课程可以修改规则、取消某一天或删除该规则，也可撤销最近一次导入。
学校时间修改后，按周次/节次的课程重新计算；原表写明的具体日期/钟点不变。
规则在本机运行。模型模式沿用「设置 → AI 模型」已有配置，会将课表内容发给该服务。
图片与扫描 PDF 需要支持识图的模型；仅规则不含 OCR。PDF 最多 8 页，单文件 30 MB，一批最多 6 个。
旧 .doc/.xls 请另存为 .docx/.xlsx；复杂合并或一格多门课需用模型或在预览中拆行核对。
尚未使用你的真实课表验证识别效果；模型输出仍需核对，课表没有说明的节假日不会自动推断。

任务、目标、习惯、回看、分段计时和本地模式不依赖 AI 服务。
开始计时后可显示置顶小窗；暂停、继续、下一段、加时与主界面同步。
小窗顶部的“—”可最小化为专注条，仅保留时间、暂停/继续和展开按钮；最小化不会中断计时。
拖动时间或空白处可移动小窗，点击专注条右侧按钮可展开。悬停时间可查看完整任务与当前步骤。
顶部返回按钮显示主界面；“×”或 Esc 只收起悬浮窗，计时继续。
退出软件会关闭计时小窗。运行中的计时会保留，重新打开时按原计时起点恢复；
如果不想累计关闭期间的时间，请先暂停或结束。
聊天附件可通过拖入或附件按钮选择；本版不支持按任意磁盘路径自动读取文件夹。
AI 功能需要联网，并在「设置 → AI 模型」中填写自己的服务地址、密钥和模型。
模型列表、文字请求和图片由 Windows 桌面程序发送，不受浏览器 CORS 限制。
是否支持图片以及是否有可用额度，以你的模型服务和连接测试为准。
模型服务可能收费；此软件不附赠服务额度。
