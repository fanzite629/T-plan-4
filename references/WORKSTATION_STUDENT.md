# 大学生工作台 · 功能设计参考

这份项目文件用于补充 T计划 的功能设计。收录版本是 @赛博老爸开发的 **Workstation Student v1.1**，可用来对照大学生场景下的界面布局和操作流程。[原项目仓库](https://github.com/cyberdaddyleo/workstation-student) · [原项目 README](workstation-student/README.md)

## 怎么查看

1. 先浏览原项目的 README 和截图，了解宿舍首页、课程表、学科资料、成绩和升学规划的布局。[界面截图](workstation-student/screenshots)
2. 如需体验交互，把仓库克隆或解压到本机，然后用 Chrome 或 Edge 打开 `references/workstation-student/index.html`。[网页文件](workstation-student/index.html)
3. 首次打开选择「先看看示例同学」，用自带示例体验。页面和主要功能可直接查看。原项目的可选 AI 接口、配置和备份步骤见 [原项目使用指南](workstation-student/docs/USER_GUIDE.md)。

## 可以参考哪些设计

| 功能 | 适合对照的设计 |
| --- | --- |
| 周课表 | 当前周和正在上课的提示、点空白时段添加课程、单双周显示、侧栏考试倒计时 |
| 学科资料 | 按课程组织笔记、附件和链接，学科页通往复习卡片、任务和专注计时 |
| 首页与专注 | 在首页呈现今天的课程和待办，从当前学科进入专注模式 |
| 学业进度 | 学期成绩、学分进度、考试与证书节点的展示方式 |

原项目的网页入口、可选 AI 中转脚本、文档和截图都在 `workstation-student/` 下，供独立预览。T计划 的实际操作见 [T计划 用户入口](../README.md)。
